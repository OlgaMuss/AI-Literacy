# AI4K12 (Five Big Ideas) - Learning Points Analysis

## Curriculum Overview
- **Developer:** AI4K12 Initiative (AAAI & CSTA)
- **Format:** Five Big Ideas poster + Cognimates activity guide + resource index
- **Target Age:** K-12 progressions
- **Focus:** Framework for AI education standards, Scratch-based coding
- **Unique Strengths:** Only depth 3 on Cognimates implementation details (wake words, substring issues, speech blocks)

## Five Big Ideas Framework
1. **Perception** - Computers perceive the world using sensors
2. **Representation & Reasoning** - Agents maintain representations and reason with them
3. **Learning** - Computers learn from data
4. **Natural Interaction** - Intelligent agents require many kinds of knowledge to interact naturally
5. **Societal Impact** - AI can impact society in both positive and negative ways
