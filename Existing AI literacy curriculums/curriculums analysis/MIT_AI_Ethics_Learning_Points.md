# MIT AI Ethics (Teachable Machine + Ethics) - Learning Points Analysis

## Curriculum Overview
- **Developer:** MIT (Educator Guide: The Brain Behind the Bot)
- **Format:** Teachable Machine activities + ethical frameworks
- **Target Age:** Middle/high school
- **Focus:** Bias in ML through hands-on Teachable Machine, EU ethical guidelines
- **Unique Strengths:** Best on EU 7 requirements detail, Teachable Machine with bias reflection

## Learning Points Coverage (Depth ≥2)

### Machine Learning with Teachable Machine (Depth 2-3)
1. **Teachable Machine** (Depth 3) - Full activity in AI Ethics curriculum with bias reflection
2. **Supervised learning** (Depth 2) - Teachable Machine demonstrates
3. **Labeled data** (Depth 2) - Teachable Machine uses
4. **Training vs test data** (Depth 2) - Teachable Machine comparison
5. **Bias in ML** (Depth 2) - Teachable Machine skewed data exploration
6. **Sources of bias** (Depth 2) - Teachable Machine reflection on data choices
7. **Mitigation strategies** (Depth 2) - Teachable Machine adjustments and diverse data

### EU Ethical Guidelines (Depth 2-3) - MOST DETAILED
1. **EU Trustworthy AI (7 requirements)** (Depth 3) - Full list with detailed explanations:
   - Human agency and oversight
   - Technical robustness and safety
   - Privacy and data governance
   - Transparency
   - Diversity, non-discrimination, fairness
   - Societal and environmental well-being
   - Accountability
2. **Creating ethical rules** - Discussed with frameworks
3. **Transparency requirement** - Detailed

### Ethics Frameworks (Depth 2)
1. **Ethical matrices** - Throughout modules
2. **Stakeholder perspectives** - Emphasis
3. **Design affects different groups** - Perspective-taking
4. **Sustainability** - Requirement in EU guidelines

### Other Topics (Depth 2)
1. **Algorithms as opinions** - Intro concept
2. **ChatGPT** - Mentioned in scenarios
3. **Environmental sustainability** - Mentioned in EU requirements
4. **Social credit systems** - China example discussed
5. **Benefits and harms** - Discussed

### Topics Mentioned (Depth 1)
1. **AI definition** - Poster context
2. **Computer perception** - Big Idea 1
3. **Data choice** - Framework mention
4. **Deep networks** - Mentioned
5. **Adversarial examples** - Video reference
6. **Societal impact** - Big Idea
7. **Cultural knowledge** (Depth 2) - Natural Interaction Big Idea: body language, facial expressions to infer intentions
