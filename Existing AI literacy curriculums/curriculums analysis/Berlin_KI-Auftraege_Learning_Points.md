# Berlin KI-Aufträge - Learning Points Analysis

## Curriculum Overview
- **Target Age:** Middle school
- **Focus:** ML applications with Pandas, advanced prompt engineering
- **Unique Strengths:** Only curriculum with depth 3 on SPEAR framework, meta-prompting, chain-of-thought, Build-a-Bot system design

## Learning Points Coverage (Depth ≥2)

### Prompt Engineering (Depth 3)
1. **SPEAR framework** - Situation, Problem, Example, Ask, Review
   - Full module with detailed implementation
2. **Role prompting** - Using personas to steer style and tone
3. **Meta-prompting** - LLM iteratively refines your prompt (activity)
4. **Chain-of-thought prompting** - Step-by-step reasoning with few-shot examples (Wei et al referenced)
5. **System prompts vs user prompts** - Reading real ChatGPT system prompt fragments, DALL-E rules detailed
6. **Build-a-Bot framework** - Persona, audience, tone, scope, adjectives with iterative design and logging

### LLM Mechanics (Depth 2-3)
1. **Temperature parameter** (Depth 2) - Low=probable, high=random/creative/errors explored via Soekia
2. **LLM token prediction** (Depth 3) - Soekia next-token exploration with n-gram picking
3. **Chatbots** (Depth 3) - Character chat activities, Soekia exploration, Build-a-Bot project

### Machine Learning (Depth 2-3)
1. **Supervised learning** (Depth 3) - Teachable Machine full activity with image classification
2. **Bias in ML** (Depth 3) - ML bias module with Pandas analysis, skewed training discussion
3. **Spam filters** (Depth 2) - ML example with pipeline explanation
4. **Mean Absolute Error (MAE)** (Depth 2) - Formula and validation in ML activities
5. **In-sample vs hold-out validation** (Depth 2) - Avoiding spurious patterns

### Data Analysis (Depth 3)
1. **Pandas** - Student data activity with retail data
   - head/tail for viewing data
   - describe for statistics
   - sort_values for ordering
   - loc for filtering
   - histograms for visualization

### Real-world Systems (Depth 2)
1. **Recommendation algorithms** - Reasoner classification activity
2. **Credit scoring, COMPAS** - ML discussions with ethical framing
3. **Target pregnancy prediction** - Full case narrative from purchase patterns
4. **Anticipatory shipping** - Amazon patent mentioned

### Other Topics (Depth 2)
1. **AI definitions** - Intelligence testing, character AI exploration
2. **Distinguishing AI from non-AI** - Activities with various systems
3. **Generative AI** - Multiple activities exploring ChatGPT and image generation
4. **Prompt engineering for images** - Style mimicry context
5. **BERT chatbots** - Activity title reference
6. **Safety: AI detection tools** - Limits mentioned
7. **Adversarial prompting** - Optional module with jailbreaks, grandmother exploit, emotional manipulation

## Not Covered (Notable Gaps)
- Neural network architecture and training mechanics
- Computer vision (edge detection, face detection/recognition)
- Reinforcement learning
- Environmental impact
- Detailed ethical frameworks (EU guidelines, ethical matrices)
- Autonomous vehicles
- Indigenous AI
- Speech recognition technical details
- GANs architecture
- Decision trees

## Total Learning Points with Depth ≥2: ~20 points

## Depth 3 Points: ~8 points
Focus areas: Advanced prompt engineering, system design, ML with Pandas, Teachable Machine

## Pedagogical Approach
- Hands-on coding (Pandas, Teachable Machine)
- Exploratory activities (Soekia temperature/token exploration)
- Design projects (Build-a-Bot with persona and system prompts)
- Real-world case studies (Target, Amazon, COMPAS)
- Optional advanced modules (adversarial prompting)
