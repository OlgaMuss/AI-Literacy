# Georgia AI4GA - Learning Points Analysis

## Curriculum Overview
- **Scope:** 3 units across 42 PDF/DOCX files
- **Target Age:** High school
- **Focus:** Robots, NLP, Machine Learning with extensive hands-on activities
- **Unique Strengths:** Most hands-on activities, only depth 3 on overfitting/underfitting/transfer learning, single neuron Boolean logic, sensor physics, homophones

## Unit Structure
- **Unit 1:** Autonomous Robots (Module 1.2-1.7)
- **Unit 2:** Natural Language Processing (Module 2.2-2.7)
- **Unit 3:** Machine Learning (Module 3.1-3.8)

## Learning Points Coverage (Depth ≥2)

### Machine Learning Pipeline (Depth 2-3)
1. **Labeled data** (Depth 2) - ML pipeline core
2. **Training vs test data** (Depth 2) - ML pipeline explained
3. **Overfitting** (Depth 3) - Portrait example: background features problem, solutions listed
4. **Underfitting** (Depth 3) - Movie revenue example with feature engineering solutions
5. **Transfer learning** (Depth 3) - Fire→fracture example, browser-based training enabled
6. **Supervised learning** (Depth 2) - ML pipeline throughout
7. **Classification Game** (Depth 3) - Students play SL algorithm role with pen-and-paper cats/dogs
8. **AI for Oceans** (Depth 3) - Fish vs garbage classifier training exercise
9. **Game controller training** (Depth 3) - Advanced TensorFlow.js option with pre-trained models
10. **Model cards** (Depth 2) - Module 3.8 objective

### Decision Trees (Depth 3)
1. **Structure: root/decision/leaf** - Pasta/candy activities with worksheets
2. **Features for classification** - Students describe features, develop splitting questions
3. **Building trees iteratively** - Step-by-step with cross-tree testing
4. **Pasta decision tree** - Full physical activity
5. **Candy decision tree** - Full physical activity
6. **Name The Reasoner** - Classification, prediction, recommendation, planning/scheduling definitions with 15+ products mapped

### Neural Networks (Depth 2-3)
1. **Architecture** (Depth 2) - Module 3.6 Learning Objectives
2. **Neurons, weights, layers** (Depth 2) - Learning Objectives
3. **Weights adjusted in training** (Depth 2) - Dog bites example
4. **Single neuron mechanics** (Depth 3) - Module 3.5b Neuron Sandbox: inputs, weights, sum, threshold, activation
5. **Boolean logic: AND/OR** (Depth 3) - 6+ problems: PB&J (AND), boots (OR), picnic (AND with weights 2,2), negative weights variant

### Natural Language Processing (Depth 2-3)
1. **Speech recognition** (Depth 3) - Module 2.2: sound waves, microphones, waveforms, spectrograms with detailed notes
2. **Spectrograms** (Depth 3) - Matching activity: frequency patterns distinguish sounds better than waveforms
3. **Homophones** (Depth 3) - Brake/break, flour/flower student activity: test speech recognizer, write sentences
4. **Speech-to-text, text-to-speech** (Depth 3) - Applications and Scratch blocks
5. **NLP field** (Depth 3) - Module 3 with full pipeline: tokenization, lemmatization, POS, syntax, semantics, intent/entity
6. **Language: symbolic, syntax** - Unit 2 vocabulary
7. **Ambiguity in speech** (Depth 2) - Module 2.3 challenges
8. **Corpus** - Vocabulary term
9. **Chatbots** (Depth 2) - Module 2.7, ChatGPT case study
10. **Word embeddings** (Depth 3) - Module 2.4 unplugged: 3D classroom axes, gumdrop example, semantic features (gender, animacy, age, number)
11. **Machine translation** (Depth 2) - Module 2.5 worksheet
