> **One-sentence claim (user revision 2026-09-17):** AI-literacy curricula are artifacts *difficult to analyse* and need to be adapted to the teaching context, which is why reuse is difficult and often requires to reinvent the wheel. Today LLMs can greatly facilitate analysis and adaptation of curricula, by **[sentence incomplete — to be completed; suggestion: "...by producing structured first-pass analyses and adaptation drafts that teachers review, adapt, and validate"]**.

### 3. Curriculum assessment and iteration proposal (~3,700 w)

#### 3.1 Methodology (~1,000 w) ★ load-bearing
- **Main points to cover:** derivation of the five dimensions from theory (Schwab's commonplaces, Klafki, Chevallard; Carroll pacing; Sweller load; formative assessment; Biggs alignment; UbD; CIPP; EQuIP as closest relative — our delta is computability + longitudinal diffing); **explicit not-a-competency-framework positioning** (seven exist and fail differently, lit review §1); learning point as the atomic reporting unit (countable, sequenceable, mappable, age-auditable); machine-readable schema proposal; coding procedure with 2-coder κ; pre-empt the measurement-narrows-curriculum critique (ISEE WG1/WG2): mastery tiering (core/working/exposure) licenses non-assessed exposure.
- **Instrument crosswalk (EQuIP × IQOer × IPN × KMK/SBZVO §5; 2026-09-22):** four universal requirements across all five — scientific accuracy/currency, target-group fit (age/prior knowledge), goal alignment, active task-based learning — plus structural consensus (criterion-based, evidence-anchored, expert-judgement verdicts). **Shared blind spot:** every instrument rates *design quality* only — Project 2061's "potential match"; none asks whether students actually learn ("empirical match… data from classroom trials are needed" — already named in the 2061 analysis guide, still unoperationalized 25 years later); only EQuIP addresses learning over time (I.D, II.G). Our T1–T7 + learning-point linkage is exactly the missing empirical layer → motivates the reporting standard as design+evidence, not design alone.
- **Reusability = our core problem construct, covered by exactly one instrument family:** operationalized only by IQOer (S3 content: self-contained, clearly delimited learning objects, no external dependencies, usable without modification; S16 technical: SCORM/IMS/LOM/LRMI standards, granularity, viewable metadata, edit-reassemble-republish; S13 CC licence = legal layer) and KMK (Veränderbarkeit/Teilbarkeit as digital-medium properties); absent from EQuIP, IPN, SBZVO. Punchline: our machine-readable learning-point schema satisfies S3/S16 *by construction* (granular, delimited, metadata-rich) — reusability through representation, not through materials polish.
- **Transversal 6th dimension (user, 2026-09-22): Reusability — not a 6th row but a probe applied within each of the 5 dimensions.** Three ordered facets = the adoption pipeline: **legibility** (≈ meaning: can an adopter understand what it *is*? — explicit learning points, stated rationale; its failure = §2.2 "no shared descriptive language"), **fit** (≈ usefulness: can they judge fit to *their* context? — declared audience/prerequisites/constraints/standards mapping; our §2.2 constraint-intersection method *is* a fit procedure), **adaptability** (reuse stricto sensu: granularity, self-containedness, editable formats, licence, shipped answer keys — IQOer S3/S16/S13; KMK Veränderbarkeit/Teilbarkeit; Wiley 5R [VERIFY — not in library]). Per-dimension probes: Context = setting documented enough to judge fit · Content = learning points self-contained/delimited · Pedagogy = activity re-enactable without the author (teacher-prep gap) · Didactics = dose/sequence rationale explicit → re-timeable (our 2–3× pacing overruns = undocumented dose) · Assessment = items + keys + scoring guidance shipped (§2.2 gap: only ENARIS). Unlike the five theory-derived dimensions ("is it good teaching?"), this one derives from the problem statement ("can anyone else use it?") — it is the framework's bridge to the title *Curricula as Data*.
- **Temporal axis of the transversal layer — curriculum ecology (user, 2026-09-22):** reuse across *time*, not only across adopters — sustainability/longevity of the artifact in a fast-moving field. Wiley's 5R (**verified 2026-09-22**: Retain / Revise / Remix / Reuse / Redistribute — Wiley 2016, [opencontent.org/definition](https://opencontent.org/definition/)) grants the *legal rights*; Wiley's **ALMS framework** (Access to editing tools, Level of expertise required, Meaningfully editable, Self-sourced — same source) names the *technical enablers*; ecology adds the *engineering discipline* that makes Revise/Remix safe over time: (1) **locality of edits** — learning-point granularity → updates touch points, not "the curriculum"; (2) **coherence = graph property** — prerequisite concept map (Concepts Atlas; Project 2061 strand-map logic) → updating a point triggers downstream-dependent / upstream-prerequisite / age-placement checks; (3) **consistency = schema contract + regression tests** — every update fills the same schema fields; the 9 Sense-B checks + alignment pipeline rerun per version (CI-for-curricula); (4) **stability tiering** — mastery tiers double as change-rate tiers (core = slow, carefully versioned; exposure = rotates with the field) → operationalizes §4's "fixed core + adaptive layer"; (5) **versioning + changelog** — the §3.4 v1→v2 diff made computable; (6) **teacher-delta coupling** — every curriculum update is a teacher update (§1) → diffs must be legible as *delta training*, not re-learning; teacher workload is an ecology constraint.
- **Lineage addition (Project 2061 → EQuIP → ours):** the 2061 curriculum-materials analysis procedure (content match incl. the "topic vs. substance" distinction = our learning-point granularity argument; pedagogical match) is EQuIP's direct ancestor; its empirical applications — Kesidou & Roseman 2002 (`tea.10035`, 9 middle-school programs) and Stern & Roseman 2004 (`tea.20019`, 9 life-science textbooks) — found the same failure modes we find in AI-literacy curricula (key ideas present but buried, prior knowledge/misconceptions ignored, no anchoring phenomena, weak scaffolding) → 20-year continuity hook for §2.2. ISEE WG1–4 stay as already-planned critique/evidence anchors (WG2 Ch. 9 measurement-narrows; WG4 EBE³ effect-size/uncertainty reporting for §4), **not** curriculum-assessment instruments; Blueprints Ch. 8 optional for §3.2 ("what is tested is what gets taught"; internal vs. external purposes; validity/reliability/feasibility/equity standards).
- **Transversal 6th dimension: Reusability (user, 2026-09-22) — "can anyone pick this up?", not "is it good teaching?":** three ordered facets as a funnel — **legibility** (meaning: adopter can understand what it is) → **fit** (usefulness: adopter can judge whether it serves their context) → **adaptability** (reusability s.s.: adopter can modify and redeploy). Probes per dimension, each backed by our own findings: Context→fit (constraints documented; our §2.2 constraint-intersection method *is* a fit procedure); Content→legibility+adaptability (verbatim, self-contained, delimited learning points — IQOer S3 items map 1:1; machine-readable — S16); Pedagogy→adaptability (activity specs re-enactable without the author — teacher-prep-gap finding); Didactics→fit+adaptability (dose/sequence rationale explicit → re-timeable — pacing-overrun finding); Assessment→adaptability (items+keys+scoring guidance shipped — §2.2 assessment-support gap, only ENARIS); artifact-wide technical/legal (format, metadata, licence — IQOer S16/S13; KMK Veränderbarkeit/Teilbarkeit). Anchors: IQOer (Müskens et al. 2021), KMK, Chevallard (every reuse = a second transposition). Derivation honesty: 5 dimensions from learning/curriculum theory; this layer from the paper's problem statement (reuse failure) — it operationalizes the title (*Curricula as Data*). Punchline: the learning-point schema satisfies IQOer S3/S16 by construction — reusability through representation.
- **Per-learning-point pedagogy coding — field rationale (each field = one construct, one anchor; implemented in `curriculum_concept_pedagogy__validation_required.csv`, auto-derived first pass 2026-09-16, human validation pending):**
  - `n_slides` + `duration_est_min` → exposure dose / opportunity to learn (Carroll 1963: learning ≈ f(time spent / time needed) [VERIFY]);
  - `icap_level` → cognitive engagement mode, passive < active < constructive < interactive (Chi & Wylie 2014 [VERIFY in library]; Four-Pillars-compatible, Meyer et al. 2021);
  - `safe_flags` → CASEL SAFE quality screen: Sequenced (revisit/recap), Active (ICAP ≥ active), Focused (≥5 min dedicated), Explicit (explicit instruction present);

  - `difficulty_drivers` → count of PISA MAIL task-difficulty drivers present per learning point (context complexity, media diversity, tool variety, higher-order thinking, open-endedness, authenticity; MAIL pp. 44–45) — computable difficulty proxy feeding the Didactics dimension;

### 4. Discussion (~1,500 w)
- Guidelines for developers / researchers / policymakers (adapt `Paper_Writing_Plan.md` §4.4).
- Multivariate design point: AI assistance for constraint-juggling, with verification norms.
- Fixed core + adaptive layer; participatory design (teachers + youth); iterative development + longitudinal analysis.
- **Age-fit of assessment-task contexts (PISA MAIL worked example, user note 2026-09-22):** the MAIL draft's exemplar task (§5.2, pp. 47–48) casts 15-year-olds as journalists who receive a verification assignment from a "manager" via a workplace chat tool — a professional-newsroom frame outside most 15-year-olds' lived experience (what a manager is/does). Notably, "authenticity and realism of the scenarios" is itself a MAIL difficulty driver (p. 45), so an age-mismatched frame risks measuring unfamiliarity with the context rather than literacy — concrete evidence for the §1 claim that frameworks/tasks are not age-specific and must be adapted to the teaching context. Source: OECD (2026) PISA 2029 MAIL assessment framework, first draft.
- Research-gap call: no empirical work on how AI-literacy curricula are developed — study the process (corpus-bounded claim, `literature_review_emergent__validation_required.md` §B).
- Limitations: single case, exploratory, small N (no generalization), generation not classroom-validated, LLM reliability, battery limits (23 items, mixed provenance), Build-group attachment may index effort not bonding (Rabb et al. 2022).
- **Gaps:** rewrite around new spine; reporting-standard call to action.
